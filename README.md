# BelaMira Moda Circular

Loja de moda circular com peças únicas, catálogo, carrinho e preparação para administração segura no Lovable.

**Importante:** este repositório contém o código-fonte. Um site público com contas, fotos e pedidos reais exige configurar autenticação, banco de dados, armazenamento de imagens e integração de pagamento. A única forma de pagamento prevista é **Pix**; o frete para destinos fora de Nova Viçosa depende de cotação efetiva dos Correios.

Não publique chaves secretas, dados pessoais de clientes ou tokens no repositório.

Arquivos adicionais e instruções de implantação serão adicionados aqui.
